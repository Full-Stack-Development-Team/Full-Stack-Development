# Server Setup & Database Connection

## Objective

Set up the Node.js backend server and establish a connection to MongoDB using Mongoose.

## Tasks

- Initialize the Node.js project inside the `server` folder.
- Install and configure Express.js.
- Configure environment variables using `.env`.
- Create the MongoDB connection in `utils/database.js`.
- Connect MongoDB using Mongoose.
- Configure the main server file.
- Verify that the server and database connection are working correctly.
